# gh-pages: forwarding page

This branch only exists so old `lsmat2.github.io` links keep working. GitHub Pages publishes it, and every page (`index.html`, and `404.html` for any other path) sends visitors to the same path on https://lsmat.com.

The real site lives on `main` and is deployed by Cloudflare. Don't merge this branch into `main` or vice versa.
